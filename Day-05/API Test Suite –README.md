# API Test Suite – Day 5 SQA Internship

## Project Overview

This repository contains the API testing assignment completed for **Day 5 of the HisabDo SQA Internship Program**.

The objective of this task was to perform manual API testing using Postman, validate API responses, document test cases, identify observations, and prepare a complete API Test Suite.

\---

## API Used

**JSONPlaceholder REST API**

Base URL:

https://jsonplaceholder.typicode.com

\---

## Testing Tool

* Postman Desktop
* Microsoft Excel
* Microsoft Word
* GitHub

\---

## Scope of Testing

### Functional Testing

The following API operations were tested:

* GET All Posts
* GET Single Post
* POST Create Record
* PUT Update Record
* DELETE Record

\---

### Validation Testing

The following validation scenarios were executed:

* Missing Title
* Missing Body
* Missing User ID
* Invalid Title Data Type
* Invalid User ID Data Type
* Invalid Record ID
* Incorrect Endpoint
* Empty Title
* Empty Body
* Duplicate Data Request

\---

### Response Validation

The following checks were performed for each request where applicable:

* HTTP Status Code
* Response Body
* Required Fields
* Data Types
* Response Structure
* Error Responses

\---

## Deliverables

This repository contains:

* Postman Collection
* Test Cases (Excel)
* Bug Report
* Screenshots
* README

\---

## Observations

During testing, several validation-related observations were identified. Since JSONPlaceholder is a mock REST API intended for testing and learning, some requests that would normally be rejected by a production API were accepted successfully. These observations have been documented in the Bug Report for reference.
