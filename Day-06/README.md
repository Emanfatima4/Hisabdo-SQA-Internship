# Day 6 – Authentication API Testing

## Objective

Perform Authentication API testing using Postman with the DummyJSON Authentication API.

## Tools Used

* Postman
* DummyJSON API
* GitHub

## Modules Tested

* Valid Login
* Invalid Login
* Missing Required Fields
* Unauthorized Access
* Token Validation

## Practical Requests Executed

1. Login Valid
2. Login Invalid
3. Empty Username
4. Empty Body
5. Missing Password
6. Missing Username
7. Wrong Username
8. Wrong Username \& Password
9. Username with Spaces
10. Password with Spaces
11. Unauthorized Access

## Deliverables

* Postman Collection
* 30+ API Test Cases
* Positive \& Negative Test Cases
* Bug Reports
* Test Summary Report

## Results

* Executed Test Cases: 11
* Passed: 11
* Failed: 0
* Unsupported Modules: Registration, Logout, Duplicate Registration (not available in DummyJSON)

## Conclusion

The available authentication endpoints were successfully tested. Login validation, missing field validation, and unauthorized access behaved as expected. Unsupported modules were documented because the selected public API does not provide those endpoints.
